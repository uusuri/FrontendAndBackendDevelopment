Соберите свой рабочий набор

Начните с того, чем пользуетесь каждый день. Затем добавьте свет и предметы, которые освободят место на столе.

01 / ВЫБОР

Для записей

Для конспектов и формул подойдёт блокнот в клетку. Если важнее видеть неделю целиком, выберите недатированный планер. Набор ручек поможет разделить темы цветом.

Выбрать канцелярию →

02 / ВЫБОР

Для рабочего света

Поворотный плафон удобен, когда нужно менять направление света. Лампа на прищепке оставляет свободной столешницу, а узкая панель подходит для небольшого стола.

Смотреть освещение →

03 / ВЫБОР

Для порядка

Подставка задаёт положение ноутбука, органайзер собирает мелочи, а коврик объединяет рабочую зону. Перед выбором сравните размеры аксессуара с доступным местом.
