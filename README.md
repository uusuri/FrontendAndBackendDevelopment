## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню: `justify-content: center`, `align-items: center`, `flex-wrap: wrap` и `gap: 16px`;
- Flexbox внутри карточек: `flex-direction: column`, `gap: 8px`, кнопки прижаты вниз через `margin-top: auto`;
- CSS Grid для карточек: `grid-template-columns: repeat(3, 1fr)` и `gap: 24px`;
- CSS Grid для каталога: колонки `260px 1fr`, именованные области `filters` и `products`.

Форма фильтров содержит категории и диапазон цен. По заданию это HTML/CSS-макет: фильтрация товаров не реализована. Медиазапросы в практике 6 не добавлялись.

Проверка в браузере: пять страниц, переходы по меню и якорям, три формы заявки и модальные окна; отдельно проверены вычисленные стили Flex/Grid и выравнивание кнопок при разной длине описаний.

### Результат аудита БЭМ

- `site-header`, `site-nav`, `breadcrumbs`, `hero`, `section`, `products-grid`, `product-card`, `catalog-layout`, `catalog-filters`, `filters-form`, `order-dialog`, `order-form`, `button`, `success-message` и `site-footer` — самостоятельные блоки.
- На страницах товаров и заявки `page-main__title` заменён на `site-main__title`: заголовок теперь принадлежит существующему блоку `site-main`.
- Во всех формах используются `order-form__input`, `order-form__select` и `order-form__textarea` по назначению.
- Вместо вложенного `.product-card .button` используется прямой селектор `.product-card__button`. Класс `button` сохранён как независимый блок, а `product-card__button` отвечает за его положение в карточке — это БЭМ-микс.
- Варианты: `product-card--featured`, `product-card--discount`, `button--primary`, `button--secondary`, `site-nav__link--active`. Модификаторы всегда используются вместе с базовым классом.
- Нет inline-стилей и CSS-селекторов по `id`. Идентификаторы сохранены для якорей, подписей полей и JavaScript. Заказ выбирается по `data-product`, поэтому переименование CSS-классов не меняет обработчик.
- Проверены страницы, состояния hover/focus, модальные окна, валидация и отправка учебных форм без передачи данных на сервер.
