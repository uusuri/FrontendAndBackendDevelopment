# ShopProject — учебный интернет-магазин

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный интернет-магазин товаров для учёбы и рабочего места. Проект КР №1 продолжает практические работы 1–4 в этом же отдельном репозитории.

## Структура проекта

- `index.html` — главная: hero-блок, преимущества, популярные товары и якорные ссылки;
- `catalog.html` — каталог, категории и статический макет фильтров;
- `product.html` — описания трёх товаров с изображениями, ценами и таблицами характеристик;
- `order.html` — отдельная страница оформления заявки;
- `contacts.html` — контактная информация и ссылка на форму;
- `css/style.css` — файл стилей;
- `js/main.js` — модальное окно и проверка формы;
- `images/` — локальные SVG-иллюстрации товаров;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Проект реализован на HTML и CSS без фреймворков и сборщика. На всех страницах используются общий CSS-файл, единая навигация и уникальные заголовки и описания. В `product.html` каждый товар имеет собственный раздел: ссылки «Подробнее» открывают нужный раздел через якорь.

### Просмотр проекта

1. Открыть опубликованный сайт: https://uusuri.github.io/FrontendAndBackendDevelopment/.
2. Для локального просмотра скачать репозиторий и открыть `index.html` в браузере. Установка зависимостей и запуск сервера не требуются.
3. Между страницами переходить через верхнее меню. На главной есть якоря «Преимущества», «Популярные товары» и «Контакты».

### Обязательные элементы

- Семантические `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`; один `main` на странице.
- Карточки товаров с описанием, ценой, ссылкой «Подробнее» и кнопкой заявки.
- Таблицы характеристик с `caption`, `thead`, `tbody`, `th`, `td` на странице товара.
- Форма с подписями, `id`, `name`, обязательными полями, проверкой e-mail и формата телефона.
- Модальное окно `<dialog>` открывается из карточек и закрывается кнопкой или Escape.
- CSS-переменные, состояния `:hover`, `:focus-visible`, `:disabled` и подсветка ошибок.
- Flexbox в шапке, меню и группах кнопок; Grid в сетке товаров, каталоге с боковым фильтром и блоках описания товаров.
- БЭМ: `site-nav__link--active`, `product-card__title`, `product-card--featured`, `order-form__input`.
- Позиционирование: карточка `relative`, её бейдж `absolute`, шапка `sticky`; порядок слоёв задан через `z-index`.

### Границы учебного проекта

Фильтры статические, кнопка применения отключена. Корзина, оплата, сервер, база данных и полноценная JavaScript-интерактивность не реализованы. JavaScript сохранён в минимальном объёме из практики №3: открытие и закрытие диалога, выбранный товар, встроенная проверка формы и учебное сообщение об успехе. Введённые данные не отправляются и не сохраняются.

Товары, цены, характеристики и адрес `shop@example.com` являются учебными примерами. Иллюстрации хранятся локально; внешние библиотеки, шрифты и изображения не загружаются.
