# Зеленая комната — магазин растений

Учебный магазин комнатных растений по практикам 9–11. [Открыть сайт](https://uusuri.github.io/FrontendAndBackendDevelopment/).

## Как посмотреть

Откройте index.html. Bootstrap 5.3.3 (CSS и JS Bundle) подключён локально из vendor/bootstrap. Подключение к интернету и сборка не нужны. css/custom.css подключён после фреймворка и сохраняет бежево-зелёную палитру. Форма проверяет ввод в браузере, не отправляет данные и не создаёт настоящий заказ.

## Что показать на защите

- Практика 9: главная — фотообложка, коллекция и гид по свету. Внутри container сетка row и col-12 / col-md-6 / col-lg-4 с g-3 показывает три карточки на компьютере; на узком экране подборку можно листать в сторону.
- Практика 10: navbar сворачивается на узком экране; в каталоге девять растений, card, btn и badge. Из каталога и карточки товара modal передаёт выбранный вид в order.html. Форма использует form-control, form-select, input-group и form-check; alert сообщает об успешной проверке. В гиде работает accordion.
- Практика 11: проверить переходы, раскрытие меню, выбор товара, ошибки формы и сообщение после корректного ввода. Исходная история сохранена в текущем репозитории; отдельный репозиторий КР №2 не создавался.

## Страницы

index.html — главная; catalog.html — каталог; category.html — лиственные; product.html — атлас характеристик; order.html — заявка; guide.html — уход; about.html — о лавке; contacts.html — обратная связь. Авторство и лицензии фотографий — на странице «О нас». Изображения видов в images/photos/, обработчики в js/main.js.
